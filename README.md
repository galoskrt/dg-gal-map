# מפת הדליפה · דיוק דיגיטלי

המשפך של גל הרוש. חמישה דפים סטטיים על GitHub Pages ב-`map.dg-gal.online`,
נבנים מהמקור שב-`src/` וחיים בשורש המאגר.

## איך בונים

```
cd tools
python buildsite.py        # מייצר את חמשת הדפים מ-src אל שורש המאגר
python build_demo.py       # מרענן את הדמו המקומי בתיקיית ההורדות
```

`buildsite.py` משתיל בכל דף את הגופן המכווץ, קובץ המותג, התמונות, ספריית
הדליפות, סיפורי הלקוחות והפיקסל. **כל דף הוא קובץ אחד עצמאי**, בלי בקשות
רשת חיצוניות מלבד ה-embed של היומן.

## בדיקות, ותמיד על התוצר ולא על המקור

```
python audit.py            # 41 בדיקות מול האתר החי
python orphans.py          # מילים יתומות ברוחב טלפון אמיתי
python inspect_png.py x.png  # קורא קריאייטיב מוגמר במספרים
python view.py --latest 3  # מכין תצוגות שאפשר לפתוח
```

**הכלל שמאחורי כולם:** שלושה ליקויים הגיעו לאוויר כי נבדק המקור ולא מה
שנשלח. `audit.py` מריץ `node --check` על הסקריפט של כל דף בנוי, אחרי
ששורת זכויות שנשתלה בתוך מחרוזת JavaScript שברה את דף התוצאה לשעות.

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `src/` | המקור. כאן עורכים, לא בשורש |
| `tools/` | בנייה, בדיקות, מסמכים וקריאייטיבים |
| השורש | התוצר שמוגש. נוצר מחדש בכל בנייה |

## המנוע

הדפים מדברים עם `dg-gal-funnel` על Cloudflare, שמחזיק את הלידים, שולח את
המיילים ומריץ את האוטומציות בוואטסאפ. הקוד שלו ב-`C:\Users\HP\dg-gal-worker`.
